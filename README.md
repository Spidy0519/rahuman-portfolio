## ✨ Features
- **Advanced Animations**: Powered by **GSAP** and ScrollTrigger for buttery smooth parallax effects, pinned scroll sections, and magnetic buttons.
- **Custom WebGL Background**: A dynamic, fluid noise-gradient shader background written in pure WebGL.
- **Brutalist Premium UI**: A highly stylized, uniform aesthetic combining hard shadows, clean typography, and tilted card layouts.
- **Live Integrations**: Real-time dashboard widgets pulling stats directly from GitHub and LeetCode APIs.
- **Fully Responsive**: Carefully crafted to look perfect on desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock Animation Platform) + Custom WebGL Shaders
- **Language**: TypeScript

## 💻 Local Setup & Development

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure you have Node.js installed on your machine (v18.x or later is recommended).

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Spidy0519/rahuman-portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd rahuman-portfolio
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the App
Start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

## 📂 Key Project Structure
- `src/app/page.tsx`: The main landing page containing the layout, GSAP logic, and WebGL shader code.
- `src/app/globals.css`: Contains custom color variables, font definitions, and global utility classes for the brutalist design system.
- `src/components/DashboardWidgets.tsx`: Contains the live API fetch logic and UI for the GitHub and LeetCode dashboard components.
